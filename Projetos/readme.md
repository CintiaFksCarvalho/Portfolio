# Projetos

Projetos desenvolvidos durante a minha formação técnica em contexto de trabalho em uma industria de polimento, aplicando conhecimentos de informática, desenvolvimento de soluções tecnológicas, análise de processos e automatização.

---

## 01. FlowRequest — Sistema de Gestão de Pedidos Internos

**Objetivo:** Otimizar a comunicação entre setores e logística, reduzindo o elevado volume de e-mails e melhorando a organização dos pedidos.

**Solução:** Desenvolvimento de uma aplicação para centralizar pedidos, organizar solicitações por setor e definir prioridades. Implementação no servidor interno da empresa, utilizando JSON para a gestão dos dados.

**Competências:** Análise Funcional | Levantamento de Requisitos | JSON | Testes Funcionais | Implementação em Servidor Interno.

**[Ver demonstração do projeto](https://cintiafkscarvalho.github.io/Portfolio/Projetos/Painel-Gestao-Pedidos/)

---

## 02. Sistema de Gestão e Planeamento Operacional

**Objetivo:** Otimizar o controlo operacional de equipas, centralizando informações de presenças, horas trabalhadas, ausências e planeamento.

**Solução:** Desenvolvimento de uma solução integrada em Excel, com dashboards diários e semanais, automatização de cálculos, controlo de movimentações entre unidades produtivas e navegação interativa entre módulos.

**Competências:** Microsoft Excel | Fórmulas | Automatização | Dashboards | Análise de Dados | Regras de Negócio.

**[Consultar ficheiro Excel e capturas de ecrã](./Gestao-Operacional/)

---

## 03. DataFlow — Automação e Tratamento de Relatórios

**Objetivo:** Melhorar a organização e visualização de dados exportados de um sistema empresarial.

**Solução:** Desenvolvimento de uma aplicação em Python para importar, tratar e reorganizar dados de ficheiros Excel, gerando automaticamente novos relatórios com campos estruturados e gráficos.

**Competências:** Python | Automação de Processos | Tratamento de Dados | Excel | Visualização de Dados.
